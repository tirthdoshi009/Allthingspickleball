# Books

Notes on books that changed how I think about playing, training, or competing. One file per
book. These are my own summaries and reactions rather than replacements for reading the
originals.

## Adding a new one

Create a file named after the book in kebab case, for example `the-art-of-learning.md`, and
add a row to the table above. A useful note tends to have:

- The core idea in a few sentences
- The parts that actually apply on court
- Something concrete to try, not just something to agree with
- A citation for the original, with any quoting kept short
